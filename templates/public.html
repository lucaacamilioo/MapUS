MapUS — UGM Campus Navigation

About

MapUS is a web-based campus navigation application for Universitas Gadjah Mada (UGM), Yogyakarta, Indonesia. It helps students, faculty, staff, and visitors find the most efficient walking route between locations across the Bulaksumur campus.

How it works

The application models the campus as a weighted graph. Dijkstra's shortest path algorithm computes optimal routes across campus pathways, rendered visually on an interactive map powered by Leaflet.js and OpenStreetMap.

Key Features

  • Shortest path computation between any two campus locations
  • Interactive map with buildings, pathways, and points of interest
  • Estimated walking time and total distance for each route
  • Search functionality for locating buildings by name

Built with

Python · Flask · SQLite · Leaflet.js · OpenStreetMap · JavaScript
